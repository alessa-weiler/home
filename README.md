## 📂 This Project

This is an AI-powered terminal portfolio built with:

**Frontend:**
- Vanilla JavaScript
- Vite
- Retro terminal styling with animations

**Backend:**
- Node.js + Express
- Claude 3.5 Sonnet (via Anthropic API)
- ElevenLabs (voice synthesis)

**Features:**
- Chat with an AI version of me
- Voice mode (speech-to-text and text-to-speech)
- Retro terminal aesthetic
- Mobile responsive

### 🚀 Quick Start

1. **Add API keys** to `server/.env`:
   ```
   ANTHROPIC_API_KEY=your_key_here
   ELEVENLABS_API_KEY=your_key_here  # Optional
   ELEVENLABS_VOICE_ID=your_voice_id  # Optional
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run both frontend and backend:**
   ```bash
   npm run dev:all
   ```

4. **Open terminal:**
   ```
   http://localhost:5173/terminal.html
   ```
