Turned it into something real: combined social simulation principles with recommender systems, built a full-stack Flask app with TypeScript, designed the entire interface from scratch.

When therapists said it was too risky to adopt early-stage, I pivoted the core compatibility engine into a friend-matching platform. Same fundamental challenge—predicting human connection—different use case.

How I think about design

Start with the user's actual problem, not the solution you want to build.

Build things you can actually ship. Prototype fast, test with real users, iterate based on feedback.

Empathy is a skill, not a personality trait. Understanding users requires structured observation and good questions.

Technical constraints are design constraints. Code your own prototypes to know what's actually possible.
